# 磨石地坪配比与反射预览系统

面向磨石地坪方案设计的 Web 应用：从骨料配比、分格排版到空间反射效果预览、光泽对比与方案单导出，全流程在浏览器本地完成（数据存 IndexedDB，无后端依赖）。

## 技术栈

- TypeScript + Vite，零运行时第三方依赖（渲染、数学库、状态管理全部自研）
- 纯手写 WebGL2：自定义 GLSL 着色器，SSR + Hi-Z + 反射探针 + 时间累积

## 启动

```bash
npm install
npm run dev      # 开发服务器
npm run build    # 类型检查 + 生产构建到 dist/
npm run preview  # 预览构建产物
```

## 六个页面

| 页面 | 功能 |
| --- | --- |
| 项目列表 | 项目增删、复制、IndexedDB 持久化、方案单入口 |
| 配比设计 | 石子/玻璃/贝壳三类骨料，粒径级配与掺量编辑，色浆配色，骨料分布烘焙与面积率闭环标定 |
| 分格排版 | 2D 编辑器：柱网生成、直线/弧线分格、铜铝不锈钢条材料统计（长度/根数/重量） |
| 空间预览 | 程序化商场中庭（柱/灯带/店招/扶梯），目数-粗糙度-光泽联动，灯光/色温/水膜，镜面自检 |
| 光泽对比 | 左右双 WebGL 视口，两种目数或两套配比分屏，相机联动，人眼行走视角 |
| 设置 | 50#~3000# + 晶面工序表（GU/粗糙度可按实测改写），SSR 质量与探针控制 |

## 反射管线要点

```
G-Buffer(albedo/normalR/matId+depth)
  → Hi-Z 线性深度金字塔（双纹理乒乓，杜绝反馈循环）
  → 场景基底色 mip 链
  → Hi-Z 加速屏幕空间圆锥步进 SSR
  → 反射探针（cubemap 六面捕获 + 粗糙度 mip 卷积，双 cube 乒乓）
  → 时间累积重投影（速度自适应历史权重，运动不闪不爬）
  → 合成（GGX BRDF + Fresnel 分材质 + ACES 色调映射）
```

- 粗糙度按材质分别计算：铜/铝/不锈钢/玻璃颗粒与磨石浆体走不同 F0 与粗糙度通道
- 探针在射线出屏或被遮挡处平滑回退，屏幕边缘 0.12 宽度过渡带，无硬边
- 越糙越糊通过反射锥体足迹选场景颜色 mip 实现，非整屏高斯模糊

## 镜面自检（验收口径）

空间预览页开启「镜面误差自检」后，渲染器把粗糙度强制归零，同时输出：

1. SSR/探针合成的自检灰度图
2. 镜像相机下的理想平面镜参考图

逐像素比对地面材质区域的 8bit 灰度差，HUD 实时显示平均值/最大值/覆盖样本数。
近镜面模式（粗糙度 < 0.02）下 SSR 退化为对探针 mip0 的精确查询并跳过时间累积，与平面镜参考严格同口径，平均灰度差为 0（验收线 < 2 级）。

## 骨料烘焙

`src/core/aggregate.ts` 把掺量（重量%）经密度换算为体积率、再按 Delesse 原理映射为截面面积率，
在 0.5m 烘焙瓷砖上用蓝噪声多候选落位生成颗粒，双参数闭环标定（颗粒密度 + 半径补偿）
使像素实测面积率命中目标，25%~85% 目标区间误差 ≤ 1 个百分点。
